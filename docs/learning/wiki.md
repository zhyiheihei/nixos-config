# wiki 学习笔记

## 1. 是什么

`nix-community/wiki` 只是旧“非官方 NixOS wiki”的占位仓库，内容已
清空并归档。README 说明它已被 [NixOS/nixos-wiki-infra](https://github.com/NixOS/nixos-wiki-infra)
和 [wiki.nixos.org](https://wiki.nixos.org) 取代。MIT，维护者
Mic92，102 star。

## 2. 现状

- 仓库只有 README、LICENSE 和 .gitignore；
- 实际文档历史都在 wiki.nixos.org 和 nixos-wiki-infra；
- 对我们来说没有可学习的技术内容，只作历史记录。
