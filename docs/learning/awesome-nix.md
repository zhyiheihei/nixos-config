# awesome-nix 学习笔记

## 1. 是什么

`awesome-nix` 是 Nix 社区的精选资源清单，按类别维护：

- 学习资源与教程；
- 安装介质与镜像生成；
- 部署工具；
- 虚拟化；
- 命令行工具；
- 开发与 DevOps；
- 各编程语言打包方案；
- NixOS modules、配置编辑器、overlay、发行版与社区。

它不是工具，而是“发现地图”，适合用来找下一个要学的仓库。

## 2. 对我们有用的部分

- 学习区：`Nix Pills`、`nix.dev`、`Zero to Nix`、`NixOS & Flakes Book`；
- 部署区：`colmena`、`deploy-rs`、`comin`；
- CLI 区：`nh`、`comma`、`nix-index`、`nix-init`、`nurl`；
- 开发区：`flake-parts`、`flakelight`、`devshell`、`treefmt-nix`；
- 打包区：`dream2nix`、`poetry2nix`、`crate2nix`、`naersk`。
