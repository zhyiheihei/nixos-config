# ZurichZHF 学习笔记

## 1. 是什么

`ZurichZHF` 是苏黎世 Nix 社区的“半年一度 NixOS 开发工作坊 +
ZHF（Zero Hydra Failures）发布 hackathon”仓库：两天免费活动
（含食宿），场地在 OST Rapperswil-Jona 校区，站点
[zurich.nix.ug](https://zurich.nix.ug)。9 star，无 license，
2025-05 还有活动更新。

## 2. 组织方式

- README 给出 When/Where/Who/What：活动日期、地点、面向所有 Nix
  用户/贡献者/维护者；
- 报名走 Meetup（nix-zurich），议程在 pad.lassul.us 协作，重要
  提案开 GitHub issue；
- `2023-05-report` / `2023-11-report` / `2024-05-report` /
  `2024-11-report`：每期报告（README + 现场照片），详细报告贴在
  discourse.nixos.org。

## 3. 对我们仓库的启发

- 我们不需要参加苏黎世活动，不引入；
- 它是社区线下活动的标准信息仓库形态：README 做公告 + 报告目录
  存档 + 外链详细内容；
- 对 nix-community 组织运营有背景价值，学习时归入“社区运营”
  类即可。
