# human 文档（给人看的）

本目录是「给人看的」指南与记录：入门、服务指南、硬件适配、调研、学习笔记、
迁移记录。agent 需用时也读。给人看的判定：**使用/阅读导向，而非执行规范**；
过时/已完成记录直接删除（归档已清理，追溯用 git 历史）。

| 子目录 | 内容 |
| --- | --- |
| [`getting-started/`](getting-started) | 入门：适配自己的设备、客户端入网、非 NixOS 设备加入知识链 |
| [`hardware/`](hardware) | 硬件适配：ARM 开发板、x86 设备、VPS 适配手册 |
| [`infrastructure/`](infrastructure) | 基础设施整合：AI 链 ↔ 知识链 |
| [`network/`](network) | 网络方案：LTNET 中继、分地区 DNS、DN42 拓扑、Flclash 配置 |
| [`services/`](services) | 服务使用指南：媒体链路、Memos、Ignis、Frigate 等 |
| [`research/`](research) | 调研记录：路由器/开发板选型、方案评估（含 README 索引） |
| [`learning/`](learning) | 项目相关的学习笔记（复刻总纲、知识链、实际使用工具） |
| [`migrations/`](migrations) | 进行中的迁移与对齐记录 |
| [`reference/`](reference) | 参考资料：[仓库结构详解](reference/repository-structure.md) |
