# rfc39-record 学习笔记

## 1. 是什么

`rfc39-record` 是一个极简数据仓库（1 star，无 license，2026-08
仍在使用）：按 NixOS RFC 39 相关流程，记录各项目团队发出过的
GitHub 邀请（用户 ID 列表）。没有代码，只有几个纯数据文件。

## 2. 内容

- `../../human/learning/README.md`：只有一行标题；
- `home-manager-invitations`：home-manager 团队邀请过的 GitHub
  用户 ID 列表（每个 ID 一行）；
- `nixvim-invitations`：nixvim 团队邀请记录；
- `stylix-invitations`：stylix 团队邀请记录。

## 3. 对我们仓库的启发

- 我们不需要邀请记录，不引入；
- 它说明 nix-community 里也有“纯数据/流程记录”仓库：团队权限
  管理靠小文件版本化，避免把邀请历史塞进各自项目仓库；
- 这类仓库价值在约定和流程，学习时记作用即可。
