# meetup-london 学习笔记

## 1. 是什么

`meetup-london` 是伦敦 Nix 社区的 meetup 协调仓库：用 GitHub 代替
每年 $280 的 Meetup 付费小组（Apache-2.0，11 star，2020-09 后
基本停更）。README 说该仓库**只做活动协调**，避免订阅者收到
讨论噪音；日常讨论引导到 nixos.org/community。

## 2. 运作方式

- 活动以 **issue** 形式发布，想参加的人在 issue 里评论报名；
- 需要登记真名（如楼宇安保）时按需通过邮箱收集；
- 通过 **watch 仓库**接收新活动通知，不想要就 unwatch；
- 纯 GitHub 工作流，没有网站/付费服务。

## 3. 对我们仓库的启发

- 我们不需要伦敦 meetup，不引入；
- “用 issue 当活动公告 + 评论报名、watch 当订阅”是零成本社区
  协调模式，值得本地社群或线上 meetup 借鉴；
- 它也说明 nix-community 名下不全是代码仓库，还有社区运营类
  仓库，学习时按内容类型记录即可。
