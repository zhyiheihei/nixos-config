# google-summer-of-code 学习笔记

## 1. 是什么

`google-summer-of-code` 是 Nix 社区协调 GSoC（Google Summer of
Code）的仓库：学生申请、导师报名、项目想法都通过 PR/issue 管理。
10 star，无 license，2024-02 已归档；README 开头写明仓库已迁到
[NixOS 组织的 gsoc 仓库](https://github.com/nixos/gsoc)，让 GSoC
参与更“官方”。

## 2. 内容

- `2018/projects.md`：项目想法列表；
- `2018/mentors.md` / `2018/students.md`：导师/学生名单；
- 参与方式：导师 PR 加自己到名单并挂到项目；学生 PR 报名并选择
  项目；也可带自己的 idea 来谈；
- 沟通：#nix-gsoc IRC 频道或仓库 issue。

## 3. 对我们仓库的启发

- 我们不需要 GSoC 协调，不引入；
- 它和 projects（资助提案库）一样属于“社区运营文档仓库”；
- “仓库迁到更正式的组织后归档旧地址”的模式再次出现，与
  flake.nix、darwin-build-box 一致——旧仓库只保留链接/历史。
