# ml-2700（Dell Wyse 5070 类小主机，AMD Vega 3 APU）

桌面客户端，与上游 `lt-dell-wyse` 对齐。`hosts/ml-2700/*.nix` 不写注释，理由记录在
本文件。

## 可选模块

- 导入列表与上游 `lt-dell-wyse` 逐字对齐（含注释占位）。上游有、本机不用的：
  `pipewire-network-audio-receive`、`sunshine`（Sunshine 在本机启用但主机级覆盖设置，
  见下）。`xvcd.nix` 目前停用。
- `wireplumber-disable-hdmi-audio.nix` 与上游逐字对齐，但规则里的 PCI 卡路径
  （`alsa_card.pci-0000_04_00.0`）是 wyse 机型的，在本机匹配不到、静默不生效；需要
  时在目标机用 `wpctl status` 找到实际 HDMI 音频卡名后替换。

## 备份

整机 restic 备份与作者 `lt-hp-omen` 逐字对齐（路径 `lantian`→`zhyi`）；client 默认
不启用 backup，此处显式启用。快照源必须是 btrfs subvolume：本仓标准装机布局不建
subvolume、`/nix/persistent` 是普通目录，原写法快照必然失败（备份从未跑通）。改为
快照整个 `/nix` 子卷（同 ml-laptop `fd83c18ed`），实际传输仍只入 persistent 子目录
（`one-file-system` 跳过 `/nix/store` 独立挂载点）。

## 显示 / 输入 / 串流

- 划词翻译 `Ctrl+Alt+E`，KDE Wayland 下经 crow 的 D-Bus 接口触发。
- **Sunshine**（`optional-apps/sunshine.nix` 是公共模块，保持不动）：主机级放开
  `allowed_origins` 才能让 LAN/LTNET 浏览器打开 Web UI（否则 CSRF 保护挡住配对页），
  逗号分隔是因为该设置只接受 atom。
- **VA-API 驱动**：AMD APU（Vega 3），而 `client-components/xorg.nix` 把 Intel 默认的
  `LIBVA_DRIVER_NAME=iHD` 设进环境，会破坏本 GPU 的 VA-API；主机级覆盖成 `radeonsi`
  才能硬件编码。运行中的用户会话在登录时已继承 iHD，只改 `/etc/environment` 到下次
  登录前到不了 sunshine 用户单元，所以在单元本身钉住这个变量（重启即生效）。
- **编码器**固定用成熟的 VA-API 硬件编码：默认的 `h264_vulkan`(RADV) 在本 APU 上
  产生块状伪影，而 Sunshine 的编码器优先级里 vaapi 排在 vulkan 之后，必须显式指定。

## 网络

- 双千兆口接家庭交换机 S5700S（`192.168.0.12`）做静态聚合出 2000M LAN。交换机侧是
  Eth-Trunk 1（`mode manual load-balance`，成员 GE0/0/5+6），两端都不跑协商：主机
  部署、拔插任意一根线都不会断网（死链自动剔除，恢复后自动回组）。IP/网关从原 NM
  手工 profile（"有线连接 2"）迁到 networkd 声明，写法对齐 rock5c/opi5p 的 home-lan
  网络；`eth0`/`eth1`/`bond0` 从 NM 摘除，桌面 WiFi 等仍归 NM。按永久 MAC 绑定，
  防止探测顺序变化导致 slave 丢失；bond 的 MAC 钉在 `eth1` 的烧录地址上，ARP/交换机
  表在重启与 PCIe 探测顺序变化后保持稳定（对齐 opi5p bond0 的做法）。
- 聚合模式 `balance-xor`：逐流哈希（与交换机侧 SIP-XOR-DIP 对应），静态聚合下不产生
  乱序；不用 `balance-rr`（逐包轮发，对端逐流哈希会乱序伤 TCP）。
- 彻底禁用 NM（对齐 opi5p/rock5c 先例）：保留 NM 时它会在 networkd 建 bond 的窗口里
  抢回 `eth0`/`eth1`，直接把链路打死（2026-09-22 实际翻过车）。桌面的无线暂未使用，
  后续需要 WiFi 再单独处理。
- 挂 opi5p（家庭文件服务器）的 NFS 共享，对应作者客户端挂 `lt-home-vm:/storage` 的
  做法；automount、非阻塞。`/mnt/storage.mount` 加 `StartLimitIntervalSec=0`：自动
  挂载的失败不撞 5 次/10s 限流，存储端离线恢复后访问即自愈（同 lubancat1/opi5p，
  `2453d5d96`）。

## 硬件文件

`hardware-configuration.nix` 由 `nixos-generate-config` 生成，不要手改（改
`configuration.nix`）。唯一的主机级改动是 swapfile 移入独立子卷 `/nix/swap`
（2026-09-01 dragon-q8b 同款先例）：放在 `/nix` 下会让 `backup-nix-persistent` 对
`/nix` 的快照报 "Text file busy"；快照跳过嵌套子卷，故 `/nix/swap` 不再阻碍每日备份。
